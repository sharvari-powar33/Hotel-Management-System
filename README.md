# 🏨 Hotel Management System

This is a Python-based Hotel Management System built using Tkinter and SQLite.

## 🔥 Features:
- Room booking system
- Customer management
- Check-in / Check-out
- Billing system
- GUI interface

## 🛠️ Technologies Used:
- Python
- Tkinter (GUI)
- SQLite (Database)

## ▶️ How to Run:
1. Install Python
2. Run the file:
   python hotel_management.py
